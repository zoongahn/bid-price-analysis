## 7. 업종제한여부(indstrytylmtyn)와 종목정보 관계

`notice.indstrytylmtyn` 컬럼은 해당 공고에 업종제한이 있는지를 나타내며, 이 값과 `notice_industry_type` 데이터 존재 여부가 밀접하게 연관됨:

| 업종제한여부 | 전체 공고 | 종목정보 있음 | 비율 |
|-------------|----------|--------------|------|
| **Y** (있음) | 2,249,975 | 2,249,919 | **100.00%** |
| **N** (없음) | 91,894 | 11 | **0.01%** |
| NULL | 4,687,489 | 2,061,478 | 43.98% |

## 8. 결론

### 8.1 데이터 수집 현황

- **notice_industry_type**: 2025년 1~10월 데이터 누락 발견 → **수집 완료** (569,510건)
- **notice_region**: 누락 기간 없음, 정상 수집 상태

### 8.2 종목/지역 정보가 없는 공고의 원인

종목정보 또는 지역정보가 없는 공고는 **수집 누락이 아니라 API에서 제공하지 않는 데이터**:

1. **`indstrytylmtyn = 'Y'`인 공고**: 거의 100% 종목정보 보유
2. **`indstrytylmtyn = 'N'`인 공고**: 종목정보 거의 없음 (0.01%)
3. **`indstrytylmtyn = NULL`인 공고**: 약 44%만 종목정보 보유

→ 업종제한이 설정되지 않은 공고는 면허제한정보 API에서 데이터를 반환하지 않음

### 8.3 둘 다 없는 공고의 특성

- 주로 **물품구매** 또는 **용역** 공고
- 조달청/나라장터 자체 등록 공고 100%
- 업종제한여부(indstrytylmtyn)가 NULL인 경우 95.65%
- 기초금액, 낙찰정보 보유율이 상대적으로 낮음
