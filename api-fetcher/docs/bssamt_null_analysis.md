# bssamt(기초금액) NULL 원인 분석

> 분석일: 2026-01-12

## 1. 개요

`data.notice` 테이블의 `bssamt`(기초금액) 컬럼에 NULL 값이 많은 원인을 분석하고, 데이터 재수집을 통해 개선한 결과를 정리한다.

### 1.1 기초금액이란?
- 입찰 시 예정가격 산정의 기준이 되는 금액
- 공사/용역/물품 각각 다른 API에서 수집됨
- MongoDB 컬렉션에서 PostgreSQL로 동기화 시 병합됨

### 1.2 관련 MongoDB 컬렉션
| 카테고리 | 컬렉션명 |
|---------|---------|
| 공사 | `입찰공고정보서비스.기초금액조회-공사` |
| 용역 | `입찰공고정보서비스.기초금액조회-용역` |
| 물품 | `입찰공고정보서비스.기초금액조회-물품` |

### 3.2 사유별 상세 설명

#### 1. 외자 (API 미제공)
- `bsns_div = '외자'`인 공고
- 외자 입찰은 별도 체계로 운영되어 기초금액 API에서 제공하지 않음

#### 2. 취소공고
- `ntcekindnm = '취소공고'` 또는 `chgntcersn LIKE '%취소%'`
- 취소된 공고는 입찰이 진행되지 않으므로 기초금액 불필요

#### 3. 전자시담 (수의계약)
- `bidmethdnm = '전자시담'`
- 수의계약은 경쟁입찰이 아니므로 기초금액 산정 불필요

#### 4. 직찰 (오프라인)
- `bidmethdnm = '직찰'`
- 오프라인 입찰은 전자조달시스템 외부에서 진행되어 API 미제공

#### 5. 연구용역 (구조적 미제공)
- `bsns_div = '용역'` AND `bidntcenm LIKE '%연구%' OR '%학술%'`
- 연구용역은 기초금액 산정 체계가 다름

#### 6. IT/SW용역 (구조적 미제공)
- `bsns_div = '용역'` AND `bidntcenm LIKE '%SW%', '%소프트웨어%', '%정보시스템%', '%정보화%', '%SI%'`
- IT용역은 기초금액 산정 체계가 다름

#### 7. 추정가격만 있음 (기타)
- `presmptprce IS NOT NULL` AND `bssamt IS NULL`
- 추정가격은 있으나 기초금액이 없는 경우
- 아래 세부 분석 참조

#### 8. 원인 미상
- 위 조건에 해당하지 않고, 추정가격도 없는 공고

## 6. Secondary Syncer 개선

### 6.1 문제점

기존 동기화 로직에서 보조 컬렉션(기초금액, 낙찰정보, 사업자상태)이 메인 공고 동기화 이후에 수집될 경우, `is_synced` 플래그가 마킹되지 않아 동기화에서 누락되는 문제 발생.

### 6.2 해결책

`secondary_syncer.py` 추가:
- 메인 동기화 이후 보조 컬렉션 동기화 전담
- `notice_is_synced` 플래그로 별도 관리

### 6.3 낙찰정보 최적화

낙찰정보는 공고당 여러 입찰이 있지만 notice 테이블에는 1건만 필요:

```python
# sync_config.py
{
    "collection_name": "공공데이터개방표준서비스.데이터셋개방표준에따른낙찰정보-공사",
    "one_per_join_key": True,  # 공고당 1건만 동기화
    ...
}
```

## 7. 결론

### 7.1 NULL 원인 요약

| 구분 | 비율 | 성격 |
|------|------|------|
| 구조적 미제공 (1,4,5,6번) | ~28% | API에서 원래 제공하지 않음 |
| 불필요 (2,3번) | ~38% | 취소/수의계약으로 기초금액 불필요 |
| 기타 (7,8번) | ~34% | 물품/용역 등 기초금액 체계 다름 |

### 7.2 개선 가능 영역

1. **정보통신 종목 (7-1)**: 6번 IT/SW용역에 포함시키면 분류 정확도 향상
2. **종목정보 없음 (7-5)**: `notice_industry_type` 동기화 개선 필요
3. **과학기술 종목 (7-2)**: 5번 연구용역에 포함시키면 분류 정확도 향상

### 7.3 한계

- **물품/용역은 구조적으로 기초금액 API 제공률이 낮음**
- 공사 위주로 기초금액이 제공되며, 물품/용역은 추정가격만 제공되는 경우가 많음
- 매년 2~4만건씩 발생하는 구조적 현상으로, 수집 갭 문제가 아님
